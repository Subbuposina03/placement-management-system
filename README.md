# Placement Management System

SQL mini project for managing student placement data.

## Project Overview

This project is designed to manage student placement information using MySQL.

It includes students, skills, companies, jobs, applications, interviews and placement details.

## Tables

- Students
- Skills
- Student Skills
- Companies
- Jobs
- Applications
- Interviews
- Placements

## SQL Queries

The project includes queries to:

1. Find students who applied to more than 5 jobs.
2. Find companies offering the highest salary.
3. Find students who applied but never attended an interview.
4. Find students who have Python skill and applied for Python jobs.
5. Find the company with the highest number of selected students.
6. Find placement percentage batch-wise.

- SQL
